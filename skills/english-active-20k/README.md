# english-active-20k — 词汇激活训练系统

目标：不是"认识"两万词，而是**灵活使用**两万词。你的被动词汇量已经够大（能无障碍看剧读文档），瓶颈在激活：想说的时候调不出、调出来搭配不对、说出来的词不够准。这套系统里每一个训练都逼你**产出**。

## 系统地图

| Skill | 一句话 | 频率 |
|---|---|---|
| `en20k-audit` | 词汇激活体检：主动/被动比、拐杖词、基线画像 | 首次 + 每月 |
| `en20k-bank` | 从剧/小说/文档收割"认识但用不出"的语块入库 | 每周 2-3 次 |
| `en20k-drill` | 产出式 SRS 复习：中文情境 → 你说英文句 | **每天 10-15 min** |
| `en20k-paraphrase` | 一句三说：casual / neutral / precise | 每周 2-3 次 |
| `en20k-speaking` | 情景陪练 + TOT 复盘（standup、code review、聊剧） | 每周 2-3 次 |
| `en20k-upgrade` | 审你写的英文，逐处升级泛词/中式表达 | 每周 1 次 |
| `en20k-immersion` | 刷剧读书闭环：看前预装、看后复述收割 | 跟着兴趣走 |
| `en20k-coach` | 总教练：周复盘、排计划、月度复测 | 每周 1 次 |

## 怎么开始（第一天）
1. 对 agent 说：`/skill:en20k-audit 体检`（分 2-3 次做完）
2. 贴一段你最近看的剧的字幕或小说段落：`/skill:en20k-bank 收割这段`
3. 以后每天：`/skill:en20k-drill 打卡`；每周日：`/skill:en20k-coach 周复盘`

## 标准一天（25-40 分钟）
- drill 10 min（核心，不可断）
- speaking 或 paraphrase 15 min（隔天轮换）
- 兴趣输入照常（看剧/读书），immersion 收尾 10 min

## 数据文件
- `data/bank.json` — 语块库 + SRS 排期（唯一事实源，`en20k-drill/scripts/srs.py` 维护）
- `data/profile.md` — 体检画像（每月更新）
- `data/logs/` — 各训练日志（coach 复盘的数据来源）
- `data/plan.md` — 下周计划（coach 生成）

## 核心指标（coach 每周盯）
- **激活率** = active / passive（audit 测）
- **泛词密度** = 泛词数 / 总词数（upgrade 测）
- 拐杖词频率、三说评分、TOT 次数

## 关于"两万"的实话
受教育母语者的被动词汇约 1.5-2 万词族。对二语者，"灵活使用两万词"实际含义是：产出时能自由调用 1-2 万级词汇 + 数千语块，对应 C1-C2 产出水平（雅思口语 7.5+）。路径不是背新词，而是把已有的 1.5 万被动词汇逐步激活，同时靠刷剧和小说自然补齐到两万认知量。每天 30 分钟，预期 6-12 个月有质变。数据会告诉你走在哪一段。
