# 一句三说（en20k-paraphrase）

## 为什么
主动词汇的真功夫 = 同一个意思，能按场合调出不同层次的词。只会一种说法 = 词没激活，只是背过。同义网络越密，说话越自由。

## 流程（每次 15 分钟，做 2-3 句）
1. **选句**，三选一：
   - 用户今天想说的一句中文或简单英文
   - 从用户最近看的剧/小说里挑一句
   - 我出题（贴近用户场景：向上沟通、吐槽 bug、聊剧）
2. **用户先自己写三版**，不许查词典：
   - V1 casual（朋友聊天）
   - V2 neutral（同事、邮件）
   - V3 precise/formal（正式汇报或写作，用最精确的词）
3. **逐版点评**，每版查四件事：
   - 语法与搭配：错在哪，母语者会怎么说
   - 语域匹配：V3 里出现 `a lot of` → 换 `considerable / substantial`
   - 精确度：`very tired` → `exhausted / drained / wiped`，三者差别讲清楚
   - **沉默词唤醒**：用户明明认识但没调用的词，点名（"你认识 grueling，这里正好能用"）——这是激活率提升最快的一刀
4. **示范三版**：给出地道三版，逐处标注与用户版本的差异
5. **30 秒后二次产出**：换一个情境，让用户把 V3 的精华词重新组装再说一遍。间隔极近的第二次产出，激活效果翻倍
6. 日志追加到 `../data/logs/paraphrase.md`：
   `原句 | 用户三版 | 我的三版 | 被唤醒的词`

## 评分（每次给三个 0-5 分，供 en20k-coach 汇总趋势）
- **灵活性**：三版差异度（三版几乎一样 = 0-1 分）
- **精确度**：V3 用词的精确程度
- **地道度**：搭配与语感

## 纪律
- 先让用户说完三版再点评，不要中途打断
- 唤醒的沉默词如果反复出现（≥2 次），建议用户用 en20k-bank 入库
